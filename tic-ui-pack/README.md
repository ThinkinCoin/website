# Think in Coin UI Pack v1.0

Visual production contract for `thinkincoin.country`.

## Package contents

- `design-tokens.css` - semantic color, type, spacing, radius, motion and layering tokens.
- `tailwind-v4-theme.css` - proposed Tailwind CSS v4 semantic mapping.
- `component-contracts.ts` - React/TypeScript naming and props contract for critical components.
- `CODER-HANDOFF.md` - implementation order, integrity rules, shell contracts and required states.
- `responsive-contract.md` - desktop, tablet and mobile transformations.
- `screen-matrix.md` - complete 60-state product map.
- `assets/` - official supplied Think in Coin SVG assets.
- `Think-in-Coin_Brand-Visual-Identity-Manual.pdf` - authoritative identity source.
- `Think-in-Coin_UI-Direction-Pack_v1.pdf` - approved application direction.
- `visual-direction-board.png` - high-resolution visual board.
- `complete-production-request.md` - complete functional UI production contract.

## Target stack

Vite, React, TypeScript, React Router, Tailwind CSS, Reown AppKit, Wagmi, Viem and TanStack Query.

## First implementation milestone

Build foundations, all three shells, `AssessmentBadge`, `ClaimKindBadge`, `ClaimCard`, `EvidenceTable` + `EvidenceMobileCard`, and the Overview / Investigation / Evidence Explorer reference templates. Validate at 375px, 768px, 1280px and 1440px before expanding the remaining routes.
